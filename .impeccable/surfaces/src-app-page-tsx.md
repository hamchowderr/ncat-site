# Surface brief: marketing site (home + pricing)

Scope: Persuade. Visitors: content creators, editing agencies, podcast and media teams who already know clipping tools (Opus Clip, Submagic, Klap, Vizard). Job: understand that this is a dashboard they own that runs clipping automations by itself on their server, then join early access through the categorized intake.

## Direction contract
THESIS: Look like the clipping category on purpose (Chowderr: "it already has the look and feel that other clipping platforms have"), then win on substance: the real dashboard on screen, automations that run unattended, pay once, own it. Refuses the mock-up-heavy, dark, decorative artifact look.
OWN-WORLD: White ground, near-black ink, one violet accent (#5b3df5 family) used sparingly; soft grey panels (#f4f4f6) group content instead of outlines; Archivo display, Geist text, JetBrains Mono for step/run data; pill buttons; real platform logos in colour.
STORY: Sees the real canvas running, recognises the category, notices "runs by itself, on a server you own", browses capabilities shown as real screens, reads plain pricing stance, fills the intake.
FIRST VIEWPORT: Centered sentence-case headline with a rotating phrase pill, one-line subhead, describe-the-automation input bar with example chips, then a large soft-grey media stage starting in view showing a real dashboard recording with tabs (Automations, Files, Runs, Review).
FORM: Category standard clipping-tool landing page, card 3 of the decision round, chosen by the user over the roll; seed:fe6bba371e07c45f.
Signature interaction: the hero stage tabs swap between real silent loops of the dashboard.
FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
