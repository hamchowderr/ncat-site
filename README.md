# ncat-site

Marketing website for the NCA Dashboard by Otaku Solutions: your content, organized and clipped automatically, built on the free, open-source [NCA Toolkit](https://github.com/stephengpope/no-code-architects-toolkit).

```bash
pnpm install
cp .env.example .env.local   # optional: only the early-access form needs it
pnpm dev                     # http://localhost:3000
pnpm test && pnpm test:e2e
```

See `CLAUDE.md` for structure and conventions.
